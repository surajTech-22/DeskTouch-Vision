# DeskTouch Vision v0.3.28 — Smooth Cursor, Instant Live Connect, Keyboard Handoff & Real Phone Screen Info

DeskTouch Vision brings instant wireless reconnect, crisp proportional phone layout & specs in Displays, zero-delay right-clicks, smooth frame-synced pointer tracking, and seamless keyboard handoff between **Windows PCs and Android phones**.

- **Smoother cursor tracking with zero snap-back or edge bounce:** Normalized mouse speed for phone pixel density with sub-pixel smoothing, synced Android pointer rendering cleanly to the phone display frame cadence, prevented delayed trailing coordinates from snapping the pointer backward behind newer movements, added full-screen edge-to-edge overlay compatibility on Xiaomi phones, and smoothed live drag steps + phone edge exit protection.
- **Instant Live Connect:** Windows broadcasts immediate online announcements on startup, resume from sleep, and Wi-Fi changes; Android wakes and reconnects immediately on announcement, screen unlock, app resume, and Wi-Fi recovery, cutting trusted discovery waits from ~4 seconds down to ~100ms.
- **Seamless keyboard handoff & soft-keyboard Backspace/Enter:** Deepened editable-field focusing under the pointer, added Android IME Enter submission support, cleared stuck modifier keys automatically on edge return, and added a one-tap Keyboard focus button plus empty-field Backspace & Enter forwarding on the phone control screen.
- **Zero-delay right-click & two-finger touchpad gestures:** Triggered Android Back immediately on right mouse button press, skipped redundant pre-click TCP coordinate stalls when low-latency delivery already sent the cursor spot, and added two-finger tap right-click + two-finger drag scroll on the phone touchpad.
- **Real phone screen dimensions, rotation & hardware details:** Reads real phone resolution, orientation, rotation, pixel density, refresh rate, Android version, and app version dynamically across rotations and displays true portrait/landscape proportions + full specs right on the Windows Displays diagram.
